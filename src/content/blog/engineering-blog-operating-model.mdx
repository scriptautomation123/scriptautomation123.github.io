Shipping content consistently is easier when the blog is treated like a product.

## Principles

- Keep publishing mechanics deterministic.
- Require PR review for every post.
- Automate checks that reviewers should not do manually.

## Workflow

1. Start from [docs/post-template.mdx](../../../docs/post-template.mdx).
2. Write a focused post with one key decision.
3. Open a pull request.
4. Let CI run type checks, markdown lint, build, and link checks.
5. Merge to `main` to deploy automatically.

## Why this scales

- New contributors can follow one path.
- Build and deploy are reproducible.
- Quality stays stable as post count grows.
