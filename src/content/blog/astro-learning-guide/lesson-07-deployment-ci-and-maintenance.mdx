A fast framework still fails without operational discipline. This final lesson focuses on durability.

## CI expectations

For this repository, your baseline pipeline should always do:

- type/content checks,
- markdown lint,
- production build,
- link validation.

If any check fails, merging should stop.

## Deployment model

Use GitHub Actions for Pages deployment.

- Every merge to `main` produces a deterministic build.
- The generated `dist` artifact is what gets deployed.
- Production site configuration should live in code, not UI toggles.

## Maintenance cadence

Weekly:

- review broken links,
- merge safe dependency updates.

Monthly:

- run a quick content freshness pass,
- verify metadata quality (`description`, `tags`, canonical URLs).

Quarterly:

- audit performance trends and JavaScript drift,
- remove stale integrations and dead assets.
