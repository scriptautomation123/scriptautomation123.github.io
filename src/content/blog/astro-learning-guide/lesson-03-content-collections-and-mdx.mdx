Content collections are one of Astro's highest-leverage features.

## Why collections matter

Without schema validation, blog metadata becomes inconsistent over time.

With collections:

- frontmatter is typed,
- invalid fields fail during checks,
- rendering stays predictable.

## Current schema in this repo

The blog collection validates:

- `title`
- `description`
- `pubDate`
- optional `updatedDate`
- optional `tags`
- optional `draft`
- optional `series`
- optional `canonicalURL`

## MD vs MDX

- Use Markdown for text-first posts.
- Use MDX when embedding UI components or rich interactive examples.

## Query and rendering pattern

Typical flow:

1. `getCollection('blog')`
2. sort/filter entries
3. render in route templates

For dynamic post pages, Astro uses static paths and renders each entry into HTML.
