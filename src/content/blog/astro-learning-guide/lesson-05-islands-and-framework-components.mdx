Astro's islands model gives precise control over client JavaScript.

## Hydration directives

Typical directives:

- `client:load`: hydrate immediately.
- `client:idle`: hydrate when main thread is idle.
- `client:visible`: hydrate when component enters viewport.
- `client:media`: hydrate based on media query.

## Practical guidance

- Prefer no hydration for static content.
- Use `client:visible` for below-the-fold widgets.
- Use `client:idle` for non-critical interactions.
- Reserve `client:load` for primary UX controls.

## Anti-patterns

- Hydrating entire pages by default.
- Mixing many frameworks without clear benefit.
- Shipping dynamic behavior where plain HTML is enough.

## Exercise

1. Add one small interactive component (for example, tabbed code snippets).
2. Hydrate with `client:visible`.
3. Compare bundle impact before and after.
