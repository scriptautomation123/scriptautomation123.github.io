Routing in Astro is file-based: filenames define URLs.

## Route basics

- `src/pages/index.astro` -> `/`
- `src/pages/about.astro` -> `/about`
- `src/pages/blog/index.astro` -> `/blog`

Dynamic routes use bracket syntax:

- `src/pages/blog/[...slug].astro` handles nested post URLs.

## Layout strategy

Layouts reduce duplication across pages.

Typical responsibilities:

- Head metadata
- Header and footer
- Content container width
- Date and post title treatment

In this project, post pages are composed with a blog layout so article pages stay consistent.

## Decision pattern: page vs component vs layout

- Use a page when it owns a route.
- Use a component for reusable UI fragments.
- Use a layout when multiple pages share structural framing.
