# Astro Learning Guide Multi-Section Blob

This folder contains a consolidated blob-style entry for the Astro learning series.

- Source lessons live in this same folder with a `lesson-XX-*` filename pattern.
- The blob post renders those lessons in one long-form sequence.
- Blob publishing slug: `/blog/astro-learning-guide/lesson-00-complete-guide/`

## Canonical Lesson URL Format

Use this naming rule for every new lesson file:

- `lesson-XX-short-kebab-title.mdx`

Where:

- `XX` is a zero-padded 2-digit sequence (`01`, `02`, ..., `10`, `11`, ...).
- `short-kebab-title` is a stable, lowercase, hyphenated slug.

This file pattern maps directly to the canonical post URL:

- `/blog/astro-learning-guide/lesson-XX-short-kebab-title/`

Example:

- File: `lesson-08-routing-advanced-patterns.mdx`
- URL: `/blog/astro-learning-guide/lesson-08-routing-advanced-patterns/`
