Astro supports multiple rendering strategies. Pick one per route based on business constraints.

## Rendering modes

- Static generation (SSG): fastest and cheapest for stable content.
- Server rendering (SSR): useful when data is user-specific or frequently changing.
- Hybrid: combine static pages with selective server routes.

## Decision heuristic

Use SSG when:

- content is editorial,
- updates are event-driven (on merge),
- personalization is not required.

Use SSR when:

- output depends on request context,
- freshness must be real-time,
- user auth context changes payload.

## Data fetching placement

Common places to fetch data:

- in page frontmatter for route-specific data,
- in utilities for shared fetch logic,
- during build for content indexes.
