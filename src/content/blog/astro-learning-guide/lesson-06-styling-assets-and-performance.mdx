Astro gives strong defaults, but sustained performance requires explicit budgets.

## CSS strategy

- Keep global styles minimal and intentional.
- Push route- or component-specific styles closer to components.
- Use design tokens (variables) for color, spacing, typography.

## Asset pipeline

- Use optimized images with constrained dimensions.
- Prefer modern formats where possible.
- Keep hero assets meaningful, not decorative weight.

## Performance checklist

- Measure bundle size after every interactive feature.
- Avoid layout shift from unbounded media.
- Keep third-party scripts to a strict allowlist.

## Exercise

1. Define three performance budgets:
   - page weight,
   - JS payload,
   - LCP target.
2. Add these limits to your PR checklist.
