## Oracle Cloud Always Free Services Worth Exploring

Oracle Cloud Infrastructure (OCI) has one of the most generous Always Free tiers
in the industry. Beyond the single VM used for the projects above, these
enterprise-grade services cost nothing while you stay within the limits.

### Autonomous Databases (2 Free Instances)

- Choose between Autonomous Transaction Processing (ATP) for application
  backends, Autonomous Data Warehouse (ADW) for analytics, or APEX for low-code
  apps.
- Each free instance is capped at **1 OCPU and 20 GB of storage**.
- Auto-tuning and auto-patching reduce operational overhead.

### OKE and Container Registry

- Managed Kubernetes (OKE) is available on the free tier.
- The Container Registry provides up to **500 GB** for custom Docker images.
- Useful for learning container orchestration without running your own control
  plane.

### Enterprise Observability

- **Monitoring:** 500 million ingestion data points per month.
- **Logging:** 10 GB per month.
- Set alarms via email or SMS for CPU, memory, or service health issues.

### Email Delivery

- Send up to **3,000 transactional emails per month** through an SMTP relay.
- Useful for password resets, verification emails, and notifications from your
  self-hosted apps.
