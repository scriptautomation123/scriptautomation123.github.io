## Critical Model Requirements and Best Practices

While you can plug in almost any model, Hindsight relies on specific LLM capabilities to execute its three memory steps effectively. [11, 12]

| Memory Operation | What it Does                                                                            | Model Requirement                                                                                                | Best Practice Models                                                                                                              |
| ---------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Retain           | Extracts multi-dimensional, atomic facts from text.                                     | High structural awareness and basic JSON parsing.                                                                | Almost any capable model, including small local models like Qwen 9B or Llama 8B.                                                  |
| Recall           | Executes multi-strategy text and vector searches.                                       | LLM-free path. Hindsight processes this algorithmically, bypassing the LLM to save token cost and lower latency. | N/A, handled natively by Hindsight's vector layer.                                                                                |
| Reflect          | Deduplicates beliefs, resolves contradictions, and manages a traceable knowledge graph. | Native tool-calling or function calling. This step requires complex reasoning to update the graph correctly.     | Premium frontier models such as GPT-4o or Claude 3.5 Sonnet. If running locally, use a model explicitly trained for tool-calling. |
