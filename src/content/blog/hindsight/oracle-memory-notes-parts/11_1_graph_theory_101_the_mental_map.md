## 1. Graph Theory 101 (The Mental Map)

Think of a graph as a web of dots connected by strings. In programming and math, we use specific names for these. [1, 6, 7]

- Vertices or Nodes: The dots. In Hindsight, every node is an Entity, for example User, Database, or Error 404, or a specific Fact.
- Edges: The strings connecting the dots. These define the Relationship between entities, for example Database HAS_ERROR Error 404.
- Weights: The thickness or strength of the string. If a user encounters an error multiple times, the edge weight gets heavier, signaling to the agent that this connection is highly relevant. [1, 5, 6, 8, 9, 10]

Traditional vector search treats memories like single sheets of paper tossed into a pile. Graph memory treats them like a structured mind map where everything has context. [11]
