## 2. Observation Consolidation

When memories are stored via retain, Hindsight runs a background process to group related facts into Mental Models or Observations. [4, 8, 10]

- Deduplication: Overlapping facts fuse into single durable observations instead of repeating. [4]
- Evidence Tracking: Every observation maps to a precise proof count and the original source text quote. [4]
- Continuous Refinement: If new memories contradict or update older ones, Hindsight updates the observation while maintaining historical lineage, ensuring temporal correctness. [3, 4]
- Freshness Verification: If an observation is labeled stale, meaning new facts have been retained but not yet consolidated, reflect will automatically cross-examine raw data chunks before relying on it. [4]
