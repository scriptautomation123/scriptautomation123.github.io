# scriptautomation123.github.io

Principal-engineer style GitHub Pages blog powered by Astro and MDX.

## Stack

- Astro static site
- Markdown and MDX content collections
- GitHub Actions CI and GitHub Pages deployment
- Markdown lint and automated link checking

## Quick Start

```bash
npm ci
npm run dev
```

Open `http://localhost:4321`.

## Content Workflow

1. Create posts in `src/content/blog/`.
2. Use the template in `docs/post-template.mdx`.
3. Open a pull request.
4. Merge after CI checks pass.
5. Deployment to GitHub Pages happens automatically on `main`.

## Frontmatter Contract

Validated in `src/content.config.ts`:

- `title`: string
- `description`: string
- `pubDate`: date
- `updatedDate`: optional date
- `tags`: string array
- `draft`: boolean
- `series`: optional string
- `canonicalURL`: optional URL
- `heroImage`: optional image

## Engineering Quality Gates

Run locally before opening PRs:

```bash
npm run validate
```

This executes:

- `npm run check` (Astro type/content checks)
- `npm run lint` (Markdown lint)
- `npm run build` (production build)

CI also runs link checks on Markdown and MDX files.

## GitHub Pages Setup

1. In repository settings, set Pages source to `GitHub Actions`.
2. Confirm default branch is `main`.
3. Push to `main` to trigger `.github/workflows/deploy.yml`.
